# LinkedIn post prompt (edit freely — the code loads this file at runtime)

Turn the transcript below into ONE LinkedIn post.

Rules — follow them strictly:
- Start with a hook: the single most surprising or useful claim from the transcript, in the speaker's own words where possible.
- Then give 3 concrete takeaways, each one sentence, each traceable to the transcript.
- End with one genuine question that invites a reply about the topic — not a generic "what do you think?".
- Only use facts and numbers from the transcript. Never invent a result or a statistic.
- Keep it under 1,300 characters. Add at most 3 relevant hashtags at the end.
