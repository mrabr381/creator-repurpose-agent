# Show notes prompt (edit freely — the code loads this file at runtime)

You are writing show notes for a podcast / YouTube episode from the transcript below.

Rules — follow them strictly:
- Only use facts, names, numbers and claims that appear in the transcript. Never invent a guest, a statistic, a link, or a claim.
- Structure: a 2–3 sentence overview, then "Key points" as 5–7 bullets in the speaker's own words, then "Key topics" as a short list.
- Keep it skimmable and useful: a listener should be able to decide in 30 seconds whether to listen, and find the part they care about.
- Do not add calls to action, links, or sponsor copy that are not in the transcript.
