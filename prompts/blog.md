# Blog post prompt (edit freely — the code loads this file at runtime)

Turn the transcript below into a readable blog post (700–1,200 words).

Rules — follow them strictly:
- Only use facts, names, numbers and claims that appear in the transcript. Never invent examples, statistics, or quotes.
- Structure: a clear title, a one-paragraph summary of the core idea, then headed sections for each main point, ending with a short "Bottom line".
- Write in the speaker's voice where possible. If you quote the speaker, copy their words exactly — never paraphrase inside quotation marks.
- Do not add an introduction or conclusion that claims things the episode never said.
